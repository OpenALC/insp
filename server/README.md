# Linux 同步服务预留

此目录只定义后续服务边界，当前没有 Go 服务、Docker 镜像或同步端点。

首版计划：Go + SQLite + 专用附件目录 + HTTPS，客户端协议见 `src/sync/contracts.ts`。

服务需要实现设备认证、账号隔离、operationId 幂等、baseRevision 比较、账号内 sequence 游标、tombstone、密文附件上传下载。版本更新和变更记录需要在同一事务提交；客户端不得通过 entityId 读取其他账号内容。

服务端只保存加密后的内容与必要路由元数据，不接收解密密钥。客户端完成加密和密钥恢复机制后再开放网络同步。部署备份须覆盖数据库及附件，关闭同步不能等同于已擦除所有离线设备副本。
