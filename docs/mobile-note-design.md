# 小米笔记真机观察与拾页移动端设计

2026-11-09，对照两台 Android 真机上的小米笔记（3.3.1.9、3.2.7.9）及拾页当前的编辑器。观察范围是笔记列表、新建的空白页、键盘和格式栏；未输入正文，也未测试媒体导入、AI 服务或文档导出。

| 场景 | 真机上看到的设计 | 拾页可以借鉴什么 |
| --- | --- | --- |
| 找笔记 | 两版都有双列卡片、文件夹入口和横向筛选。普通笔记显示标题、摘要和日期，思维笔记有结构缩略图。一台处于列表顶部，大标题下有搜索框；另一台处于滚动位置，标题收紧，筛选仍在顶部。 | 分组和搜索在列表内就能用。普通笔记靠摘要辨认，导图靠根节点和一层分支辨认。保留紧凑单列，让长标题和大字号也有合适的布局。 |
| 开始写 | 空白页显示标题、日期和字数；正文起笔处既可直接写，也可选“创建思维笔记”。 | 新建默认直接书写；仅在空白页提示“创建思维导图”。已有正文不用承担隐式转换的风险。 |
| 编辑 | 两版顶部都有返回、撤销、重做、完成。键盘上方先给出语音、涂鸦、选择框、附件和字体样式等入口；点字体样式，同一行就换成格式工具。 | 手机端先放拾页已有的图片、待办和“格式”。让工具随键盘移动；让正文和光标稳定，不因打开格式栏失焦或被遮挡。 |
| 找格式 | 两版首屏都是加粗、斜体、下划线、删除线、高亮。3.3.1.9 横滑还能看到三级标题、两种列表、引用、分隔线、对齐和缩进，收起按钮始终在右侧。 | 常用操作放第一层。标题、列表和段落可有带文字的入口，不必让用户记住横滑几次才能找到某个图标。 |
| 从编辑回到阅读 | 在 3.3.1.9 按一次系统返回，键盘与格式栏收起，但仍停在同一篇笔记；顶部由撤销、重做、完成换成分享、更多。 | 第一次返回留在原文，再返回列表。阅读时保留标题和正文，把编辑命令留到光标出现时。 |

**建议先改编辑器。** 拾页的 `RichTextEditor.vue` 已经支持强调、标题、列表、引用、图片和撤销；当前这些命令都在正文上方同一条横滚栏。第一步只重排手机交互，复用现有 Tiptap 命令和附件存储，不动桌面工具栏。第二步再改首页卡片和导图预览。高亮、三级标题可随后逐项接入；语音转写和 AI 涉及新的数据处理，不是第一版界面改动的前提。

最有价值的一条验收路径：**选中一段文字 → 打开“格式”并加粗 → 把光标移到下一段插图 → 收起键盘**。加粗应只影响选区，图片应在插入点，返回后应能看到刚编辑的位置。另用长标题、大字号和暗色模式检查列表；拾页沿用浅色黑字、暗色淡灰字以及自己的绿色强调色。


## 第一轮实现

移动端列表采用双列卡片和横向分组筛选；思维笔记展示中心主题与前三个一级分支，多余分支显示数量。预览从已授权解密的笔记计算，不新增明文缓存，也不读取被隐私区隐藏的内容。

富文本手机端增加阅读状态、完成按钮、底部图片/待办/格式入口；格式展开在同一区域，桌面保留原工具栏。正文点击位置用于定位光标，图片选择前保留插入位置。思维笔记的大纲改为层级线条和突出中心主题，节点操作通过“•••”展开；列表与思维树继续共享同一份文档。

Android 模拟器验证了卡片结构预览、阅读/编辑/格式切换以及列表/思维树切换前后的节点 ID 和文字一致。


## 第二轮实现

空白普通笔记可原地创建思维笔记，保留 ID、标题、分组、隐私和同步策略。仓库层仅接受空文档或空段落；文字、空格、图片、待办等内容均不会被该入口覆盖。异步图片导入完成并保存后，才允许切换笔记类型。

格式栏增加三级标题与高亮，触摸工具时保留选区；图片插入书签跟随文档事务更新，已经开始的导入在页面切换前完成。高亮在浅色下用浅黄色、黑字，暗色下用深色底、淡灰字。未新增依赖。

空白转换、原策略保留、重启后恢复及跨端接收由持久化测试覆盖；另验证含文字或图片的笔记拒绝转换。Android 模拟器实测空白转换、正文后隐藏入口、格式面板选区保留、局部高亮以及阅读状态恢复。


## 普通笔记直接进入与页面重构

新安装自动进入普通笔记。旧加密笔记一次验证原口令后，自动访问凭据交给系统安全存储保护；只有进入隐私笔记才请求系统认证或独立隐私密码。厂商私有“隐私密码”没有被当作公共接口调用；系统验证使用公开锁屏/生物认证。

侧栏底部只保留设置入口，外观、布局、安全、同步和连接设备集中在设置页及其子页。移动端列表采用收拢标题、搜索、置顶分组筛选、无描边卡片与浮动新建入口；支持宫格/列表。编辑器是独立滑入页面，元数据设置放入底部菜单，保留光标与键盘。设置页、侧栏与底部菜单使用独立进出动画，并尊重减少动态效果选项。

原生端透明状态/导航栏，按系统安全区与屏幕像素比传递 CSS 像素 inset；键盘由原生窗口负责缩小 WebView，前端只消费当前可见高度，不重复扣除键盘。手动切换浅暗外观时同步更新系统栏图标颜色。

## 输入与底部栏修复

新建栏移到列表滚动容器之外，固定于应用底部。视口高度变化只负责布局，不再推断用户已结束编辑；新笔记等编辑器真正可编辑后才请求焦点。本机已确认的同步回执只推进游标，不暂停或重置编辑器；真正的远端内容更新仍刷新文档，保留当前阅读／编辑状态。

思维笔记采用纸面层级大纲与分支连线，当前主题的新增、排序、缩进和删除集中在底部工具区。思维树使用紧凑节点与曲线连接，可双向滚动；两种呈现仍共用原文档及节点 ID。

## 思维笔记：从一个节点连续写下去

小米笔记真机上，空白大纲直接提示点击输入、回车继续；树视图把中心主题放在画布中央，点中节点后，新增入口出现在节点旁。拾页按这条输入路径设计：列表点空白提示开始分支，回车继续同级，中心主题回车创建子主题；有实体键盘时，Shift+Enter 可在主题内换行。输入法确认候选词不新增主题。

升级和降级始终可见，不能执行时置灰。降级将整支移入前一同级主题，升级将它放到父主题之后。切换视图时选中节点移动到新位置，保留选区；两个视图分别记住滚动位置，并让当前节点可见。启用减少动态效果时直接切换。

两台 Android 和一台 HarmonyOS 真机均验证了：点空白分支输入、回车创建同级、升降级、列表与树往返，以及重新打开后两条分支的内容和顺序。Android 还核对了切换前后的节点 ID、文字选区，以及减少动态效果时跳过节点位移；HarmonyOS 通过系统界面确认焦点仍在第二个分支。

中心主题就是笔记名称，直接在列表首行或树的中心改名，卡片和搜索同时更新。新建和空白转换均使用“未命名的思维笔记”。旧笔记若已有独立名称和中心内容，两者均保留，原中心连同原分支成为名称下的一个主题。

编辑顶栏按“完成 → 切换视图 → 笔记选项”排列。中间只显示目标视图的图标；正文直接从大纲或画布开始，不显示分类标题和主题计数。键盘弹起时打开选项，面板对齐收起键盘后的底边，不叠加第二段滑入动画。

手机顶栏在返回键右边直接显示、编辑笔记名称。普通笔记不再在正文上方重复标题；思维笔记的顶栏和中心节点共用名称。侧栏宽度为原来的三分之二，上限 220px。参考 Relay 的文字标识，首行“拾页 · Inspiration”靠左，次行小字“by OpenALC”靠右。

普通正文、大纲和树的双指缩放只作用于内容，保留单指滚动和文本编辑。安卓两台真机上，捏合到 150% 时，页面视口仍是 100%，顶栏与工具栏尺寸、位置不变。鸿蒙真机上用双指放大树节点时，顶栏标题边界不变。触屏点击按钮去掉系统蓝色高亮，键盘导航仍显示焦点。

Android 的键盘动画由系统驱动。在动画结束时一次性应用键盘占位，避免逐帧重排 WebView；系统栏或屏幕密度变化时才向页面更新安全区。

## 卡片打开与收起：真机补充观察

2026-11-10，在小米笔记 3.3.1.9 的普通笔记上观察打开和返回的中段画面。打开时，点中的卡片位置长出圆角页面；列表同步变暗、轻微模糊。卡片预览保持原字号并淡出，笔记正文在展开过程中逐渐出现。返回时，仍能看到原字号的正文被收缩中的页面窗口裁切，接近原卡片大小才显露列表预览。整个过程的页面轮廓、内容和背景各自运动；把整张卡片连同文字等比放大，或者先隐藏正文只缩回空白纸面，均与真机表现不同。

拾页的对应实现采用三个视觉层：遮罩负责列表明暗与模糊，裁切窗口负责页面边界，原尺寸的预览与正文在窗口移动时交叉淡化。打开前先载入目标笔记，从本次点击的 DOM 卡片记录起点；收起时复制当前可见正文和滚动位置，最后回到同一张列表卡片。原页面和动画副本只在结束时交接，避免完成动画后才突然更换内容。
